# Open Generative AI

> **Validada no benchmark.**

## Quando usar
Cliente que quer uma interface de estúdio com muitos modelos.

## Quando NÃO usar
Quando o hub de mídia próprio atende.

## Passo a passo
Baixar o aplicativo de desktop pela página de releases do repositório `Anil-matcha/Open-Generative-AI`. No macOS, rodar o `xattr -cr "/Applications/Open Generative AI.app"` indicado no README para liberar o app. Escolher o modelo na interface; os modelos de terceiros usam a chave da API de cada provedor.

## O que o benchmark mediu
Rodou em sandbox de CPU: 33.1s, pico de memória 739 MB

## Requisitos
Desktop; modelos por API de terceiros ou local com GPU. Precisa de GPU: Opcional.

## Combina com
geração de imagem/vídeo do Cérebro Pro, `direcao-de-midia`.
