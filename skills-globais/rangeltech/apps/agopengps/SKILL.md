# AgOpenGPS

> **Validada no benchmark (clone e inspeção).**

## Quando usar
Cliente agrícola que quer software livre de guiagem GPS.

## Quando NÃO usar
Fora de agricultura.

## Passo a passo
Fonte oficial: projeto AgOpenGPS (comunidade); instalar pelo instalador do Windows indicado no site do projeto.

## O que o benchmark mediu
Clonado e inspecionado em sandbox de CPU (não executado): 0.5s, pico de memória 2 MB

## Requisitos
Windows; receptor GPS e hardware de trator. Sem GPU.

## Combina com
nada no pacote.
