# Ghost

> **Validada no benchmark.**

## Quando usar
Blog ou newsletter na máquina virtual.

## Quando NÃO usar
Site de vendas (use o site próprio).

## Passo a passo
Comandos e exemplos do README oficial:

```
npm install ghost-cli -g
```

## O que o benchmark mediu
Rodou em sandbox de CPU: 13.0s, pico de memória 377 MB

## Requisitos
Node 20+, MySQL em produção, nginx; root para o `ghost install`. Sem GPU.

## Combina com
`site-na-maquina-virtual`.
