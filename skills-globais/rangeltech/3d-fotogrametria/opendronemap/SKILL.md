# OpenDroneMap

**Veredito da campanha (26 a 28/10/2026):** OK para quem instala (licença restritiva). **Classe do dado:** medido.

## Para que serve
Fotogrametria de drone. AGPL e exige Docker (INCOMPATIVEL com Vast).

> A command line toolkit to generate maps, point clouds, 3D models and DEMs from drone, balloon or kite images. 📷

## O que foi medido
- INCOMPATIVEL com instancia Vast (exige Docker)

## Hardware
Precisa de GPU. Siga a skill `gpu-barata` para escolher e alugar (ligar, usar e desligar para não pagar parado).
