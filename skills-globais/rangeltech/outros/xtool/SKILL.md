# xtool

> **Validada no benchmark (clone e inspeção).**

## Quando usar
Quem tem projeto Swift e não tem Mac.

## Quando NÃO usar
Sem projeto iOS.

## Passo a passo
Seguir o README oficial do repositório.

## O que o benchmark mediu
Clonado e inspecionado em sandbox de CPU (não executado): 1.5s, pico de memória 34 MB

## Requisitos
Linux ou Windows (WSL); conta Apple Developer do cliente. Sem GPU.

## Combina com
`swiftui-pro`.
